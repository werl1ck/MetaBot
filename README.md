# MetaBot

MetaBot is a Telegram bot for managing notes. It allows users to create and delete notes, view a list of saved notes, and search for notes by tag.

## Features

- Create new notes
- Delete notes
- View all notes
- Search notes by tag

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/werl1ck/MetaBot.git
   cd MetaBot
   ```

2. Configure your Telegram bot token in the project settings.

3. Build and run the project using the build system configured in the repository.

## Disclaimer

This is an educational project created for learning purposes. It is not intended for commercial use or other serious applications, as bugs and unexpected behavior may occur.

The project does not use a database. Notes are not stored in a database, so data persistence is not guaranteed.
